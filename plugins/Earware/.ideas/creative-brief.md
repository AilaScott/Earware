# Earware — Corrective Headphone EQ

> **HISTORICAL ARCHIVE** — pre-implementation ideation from 2026-07-30. Superseded:
> the dataset is AutoEq "Recommended Results" (6033 headphone models, 6034 list
> entries — not oratory1990's 736), and the DSP is a linear-phase FIR convolution
> with ~23 ms latency. Kept for product/creative context only.

**Developer:** Aila  
**Hook:** *"Perfect your headphones. Zero guesswork."*

**Description:** Earware is a preset-based corrective equalizer that applies
oratory1990's scientifically measured headphone correction curves. Select
your headphone model from 736+ presets (over-ear, in-ear, earbud), and the
plugin automatically applies the inverse of the headphone's measured
frequency response — flattening it to a neutral target curve. A single
bypass toggle lets you A/B the correction instantly. The EQ curve is
rendered in real-time so you can see exactly what correction is being
applied.
